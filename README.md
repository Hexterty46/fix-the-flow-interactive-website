Deze 'fix-the-flow-interactive-website' sprint, hebben wij interacties gemaakt. Ik heb ervoor gezorgd dat de AI chat opent en sluit.

## Kenmerken

Door Javascript te gebruikem opent allebei de chatten als er op geklikt word, ook sluit de chat automatisch als er op ESC word gedrukt op de Desktop versie van de website. Dit gebeurd ook allemaal met javaScript. Door JavaScript kan ik een extra laag toevoegen op de website om de chat te kunnen openen.
